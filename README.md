# arboretum-demo

## What is this?
It's a WIP. The idea is to create a web-based app that shows you earthquakes around the world in realtime.
For now, it is a Kubernetes based micro-micro-services system that pulls earthquakes data from freely available API in realtime and stores it in a db for some future frontend.

> The actual reason this exists, is because I wanted to learn some Go and remember the good old times with k8s.
